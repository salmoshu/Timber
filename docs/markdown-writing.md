# Markdown 写作（v0.6.14）

本版参考 [MarkText](https://github.com/marktext/marktext) 的[编辑体验](https://marktext.me/docs/editing)，在 Timber 的资源阅读区补齐常用写作能力。继续使用现有 Markdown 文件、编辑器、批注及导出管线，无需迁移文档。

## 入口

打开 Markdown 文档后，面包屑下方显示写作工具。阅读模式保留实时排版及原有格式栏；源码模式提供直接编辑和相同的格式操作。选中文字时，浮层同时提供格式按钮和「添加标签」。

空行输入 `/`，或按 `Ctrl+/`，即可搜索插入格式。面板支持中文与英文关键词、上下方向键、回车确认及 Esc 取消。表格可设置 1–50 个数据行和 1–20 列，另有一行表头。

插入项包括六级标题、正文、无序/有序/任务列表、引用、代码、表格、分隔线、行内/块级公式、高亮、脚注、YAML 元信息、Mermaid 示例、提示块和常用表情。阅读模式输入 `:smile:` 等名称也有 Emoji 提示。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 加粗 / 斜体 / 链接 | Ctrl+B / Ctrl+I / Ctrl+K |
| 行内代码 | Ctrl+` |
| 删除线 / 高亮 | Ctrl+Shift+X / Ctrl+Shift+H |
| 标题 1–6 | Ctrl+Shift+1–6 |
| 引用 / 代码块 | Ctrl+Shift+Q / Ctrl+Shift+C |
| 无序 / 有序 / 任务列表 | Ctrl+Shift+U / Ctrl+Shift+O / Ctrl+Shift+L |
| 表格 / 数学公式 | Ctrl+Shift+T / Ctrl+Shift+M |
| 插入面板 | Ctrl+/，或空行输入 `/` |
| 查找 / 替换 | Ctrl+F / Ctrl+H |
| 上一处 / 下一处匹配 | 查找框内 Shift+Enter / Enter |
| 保存 | Ctrl+S |
| 专注模式 | F8 或 Ctrl+Shift+J |
| 打字机模式 / 沉浸模式 | F9 / F10 |
| 退出沉浸 / 关闭面板 | Esc |

macOS 对应使用 Cmd。源码编辑的 Tab / Shift+Tab 可缩进或反缩进多行；智能回车支持有序列表递增、完成任务后新建未完成项、空列表逐层退出、引用续行和代码围栏闭合。写作设置中可以分别关闭括号引号配对和智能续行，中文输入法组词期间不会触发这些转换。

## 专注与统计

专注模式在阅读模式淡化其他段落，在源码模式突出当前行；打字机模式只在编辑时跟随光标，不接管手动滚动。沉浸模式收起项目、文件与标签侧栏，保留阅读区和退出按钮。三种模式可组合，设置在本机保存。

底部显示字词、字符、预计阅读时间、任务完成进度和保存状态。中日韩文字按字统计，其他语言按词统计；字符使用 Unicode 字素计数，组合 Emoji 作为一个字符。YAML 文档信息不计入正文，代码示例中的任务语法不计入任务进度。选中文字显示选区字词数，源码模式另有行列位置。阅读时间是按字词数量估算的参考值。

## 图片

在两种编辑模式中粘贴截图、拖入图片或点击「图片」选择文件。支持 PNG、JPEG、GIF、WebP，单张不超过 8 MB，一次不超过 20 张。后台检查实际文件内容，并生成唯一名称，保存在文档旁的 `assets` 子目录。Markdown 使用 `assets/image-….png` 这样的相对路径，移动整个文档目录仍可使用。

远程项目通过对应的 timberd 保存图片；远端需要升级到本版。图片保存期间若切换文档或原编辑位置已失效，会保留图片文件并提示重新插入，避免插入到错误位置。撤销图片插入会撤销文档中的引用，已保存的图片文件保留供复用。

## 查找与导出

查找按字面文本匹配，支持大小写和全字匹配。源码模式搜索 Markdown 源码；阅读模式搜索渲染文本。单处替换、全部替换和空字符串删除均可用；阅读模式的替换保留原有行内格式。极多匹配时先缩小查询范围，再执行替换。

HTML 导出包含排版样式、本地图片和静态 Mermaid 图表，可在关闭 Timber 后查看；网络图片保留原链接，需要网络访问。PDF、Word、长图和 A4 分页仍使用同一份 Markdown 草稿。

## 与 MarkText 的对应关系

| 体验 | Timber 的处理 |
| --- | --- |
| 实时排版、CommonMark/GFM、公式、代码高亮 | 沿用并验证现有能力 |
| 源码 / 阅读模式 | 共用草稿、快捷操作及自动保存 |
| 选区格式浮层、快速插入、表情 | 本版新增，并保留划词批注 |
| 智能续行、配对、缩进 | 本版增强源码编辑，阅读模式继续使用实时编辑 |
| 专注、打字机、沉浸、统计 | 本版新增，可组合使用 |
| 图片粘贴 / 拖入 / 文件选择 | 保存到本地或远程项目的文档附件目录 |
| 查找替换、HTML 导出 | 本版新增并加入回归检查 |
| 图片缩放对齐、表格行列操作、图表预览 | 沿用 Timber 现有工具 |

这是针对 Timber 的体验实现，没有引入或复制 MarkText 的 Muya 编辑引擎。MarkText 项目按 [MIT 许可证](https://github.com/marktext/marktext/blob/develop/LICENSE) 开源；本版参考其公开功能和交互设计。完整引擎迁移、云图床、拼写检查及 MarkText 的全部偏好选项不属于本版支持范围。

## 验证

`pnpm test:markdown` 检查文本转换、列表与代码上下文、查找、统计及 Unicode 边界；`cd sidecar && go test ./...` 检查图片内容、路径越界、不覆盖与鉴权；`pnpm build && pnpm test:markdown:ui` 使用独立 Electron 配置和临时项目验证实际 Vditor、源码编辑、撤销、图片插入和 HTML 导出。发布流程在上传安装包前执行这些检查。
