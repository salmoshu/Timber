# Markdown 写作（v0.7.2）

本版将 Timber 的所见即所得编辑迁移到内置 [MarkText/Muya](https://github.com/marktext/marktext) 源码，源码模式使用 CodeMirror 5。React/Zustand 项目架构、Markdown 文件、目录、批注数据、图片相对路径、自动保存及导出流程保持兼容，无需迁移文档。

## 入口

阅读模式由 Muya 提供实时排版、选区格式浮层和块级工具；源码模式提供直接编辑和相同的格式快捷键。顶部拨动开关切换阅读／源码模式及 A4 分页预览。面包屑下方不再显示写作按钮行。

在同一可格式化文本块中选中文字后，显示 Muya 工具条，点击其中的批注气泡图标可创建笔记或标签。批注与其他格式操作共用显示条件；跨段落等不能显示完整工具条的选区，不会单独浮出批注按钮。同一段落内的视觉换行不影响这一规则。阅读和源码模式都可用 `Ctrl+Shift+A` 批注选区。

阅读／源码拨动开关分别使用眼睛和代码图标，A4 分页预览使用页面图标按钮；鼠标悬停可查看说明，控件保留键盘和屏幕阅读器支持。任务清单使用方形勾选框，点击仍会更新 Markdown 任务状态，并可撤销。

空行输入 `/`，或按 `Ctrl+/`，即可搜索插入格式。面板支持中文与英文关键词、上下方向键、回车确认及 Esc 取消。表格可设置 1–50 个数据行和 1–20 列，另有一行表头。

插入项包括六级标题、正文、无序/有序/任务列表、引用、代码、表格、分隔线、行内/块级公式、高亮、脚注、YAML 元信息、Mermaid 示例、提示块和常用表情。阅读模式输入 `:smile:` 等名称也有 Emoji 提示。

| 无序 / 有序 / 任务列表 | Ctrl+Shift+U / Ctrl+Shift+O / Ctrl+Shift+L |
| 表格 / 数学公式 | Ctrl+Shift+T / Ctrl+Shift+M |

| 上一处 / 下一处匹配 | 查找框内 Shift+Enter / Enter |

macOS 对应使用 Cmd。切换标签和模式后保留各编辑器的撤销记录，来自另一模式的修改作为单独一步纳入当前编辑器历史。源码编辑的 Tab / Shift+Tab 可缩进或反缩进多行；智能回车支持有序列表递增、完成任务后新建未完成项、空列表逐层退出、引用续行和代码围栏闭合。在「设置 → 编辑器」中可分别控制括号、引号和 Markdown 标记配对，调整源码智能续行、代码块／源码行号、2／4／8 空格缩进和空行插入提示，中文输入法组词期间不会触发这些转换。

## 专注与统计

专注模式在阅读模式淡化其他段落，在源码模式突出当前行；打字机模式只在编辑时跟随光标，不接管手动滚动。沉浸模式收起项目、文件与标签侧栏，保留阅读区和退出按钮。三种模式可组合，设置在本机保存。

底部显示字词、字符、预计阅读时间、任务完成进度和保存状态。中日韩文字按字统计，其他语言按词统计；字符使用 Unicode 字素计数，组合 Emoji 作为一个字符。YAML 文档信息不计入正文，代码示例中的任务语法不计入任务进度。选中文字显示选区字词数，源码模式另有行列位置。阅读时间是按字词数量估算的参考值。

## 图片

在两种编辑模式中粘贴截图、拖入图片，或通过 `/` 插入图片。源码插入面板中的「本地图片」可选择文件；阅读模式使用 Muya 图片工具。支持 PNG、JPEG、GIF、WebP，单张不超过 8 MB，一次不超过 20 张。后台检查实际文件内容，并生成唯一名称，保存在文档旁的 `assets` 子目录。Markdown 使用 `assets/image-….png` 这样的相对路径，移动整个文档目录仍可使用。

远程项目通过对应的 timberd 保存图片；远端需要升级到本版。图片保存期间若切换文档或原编辑位置已失效，会保留图片文件并提示重新插入，避免插入到错误位置。撤销图片插入会撤销文档中的引用，已保存的图片文件保留供复用。

## 查找与导出

查找按字面文本匹配，支持大小写和全字匹配。源码模式搜索 Markdown 源码；阅读模式搜索渲染文本。单处替换、全部替换和空字符串删除均可用；阅读模式的替换保留原有行内格式。极多匹配时先缩小查询范围，再执行替换。

HTML 导出包含排版样式、本地图片和静态 Mermaid 图表，可在关闭 Timber 后查看；网络图片保留原链接，需要网络访问。PDF、Word、长图和 A4 分页仍使用同一份 Markdown 草稿。

## 主题与单文件

「设置 → 外观」提供 33 套配色及跟随系统，覆盖应用界面、编辑器、代码阅读、历史与架构图。Windows 安装后，在 `.md`、`.markdown`、`.mdown` 或 `.mkd` 的「打开方式」中选择 Timber 即可打开文件。单文件可编辑、批注、保存和导出，文件树与搜索仅包含该文件；打开项目文件夹后才能使用架构、历史与 Git。

「设置 → 编辑器」中的“字体系列”和“代码字体”使用 MarkText 风格的下拉框，显示当前字体。展开后可滚动完整本机字体列表，也可输入名称搜索，再点击选项或使用方向键和 Enter 选择；未匹配的名称不会被保存，Esc 关闭列表。两个下拉框分别保存，缺少的字符自动使用备用字体。Open Sans 和 DejaVu Sans Mono 随应用内置，可离线使用；原有的多字体回退偏好会继续保留，直到重新选择字体。

同一页面可调整 Markdown 正文字号（12–32 px）、行高（1.2–2 倍），以及代码块与源码字号（12–28 px）和自动换行。正文最大宽度支持自适应、舒适与窄栏预设，也可填写 `800px`、`80ch` 或 `80%`。右侧实时预览正文、粗体、斜体和代码，支持一键恢复排版默认值。改动在本机保存，旧版衬线／无衬线选择和已填写的字体列表会自动迁移；调整排版不会修改文档内容。

## Muya 与 Timber 的边界

| 体验 | Timber 的处理 |
| --- | --- |
| 实时排版、CommonMark/GFM、公式、代码高亮 | 使用内置 Muya，启用 Front Matter、脚注、提示块和 CJK 强调 |
| 源码 / 阅读模式 | Muya 与 CodeMirror 共用草稿、快捷操作及自动保存 |
| 选区格式浮层、快速插入、表情 | 使用 Muya 工具，格式工具条内提供 Timber 批注入口 |
| 智能续行、配对、缩进 | CodeMirror 源码模式保留 Timber 的 Markdown 上下文处理 |
| 专注、打字机、沉浸、统计 | 保留 Timber 写作体验设置，可组合使用 |
| 图片粘贴 / 拖入 / 文件选择 | 保存到本地或远程项目的文档附件目录；编辑时通过 `/raw/` 显示，Markdown 仅保存相对路径 |
| 查找替换、HTML 导出 | 保留 Timber 查找界面；导出嵌入本地图片、KaTeX 字体和静态 Mermaid SVG |
| 图片缩放对齐、表格行列操作、图表预览 | 使用 Muya 内置工具及 Timber 灯箱 |
| 右侧短目录线与批注面板 | 继续读取真实标题 DOM 和现有 quote/prefix/suffix 锚点，不迁移 `.timber/annotations.json` |

Muya 源码位于 `vendor/marktext-muya`，按 MIT 许可证内置。上游版本、许可证及 Timber 本地改动见该目录的 `UPSTREAM.md`。云图床、拼写检查及 MarkText 应用本身的全部偏好选项不属于本版支持范围。

## 验证

`pnpm test:markdown` 检查文本转换、列表与代码上下文、查找、统计及 Unicode 边界；`cd sidecar && go test ./...` 检查图片保存、路径边界、鉴权和单文件工作区。先执行 `pnpm build`，再运行两项界面回归：

- `pnpm test:markdown:ui` 使用独立 Electron 配置和临时项目验证 Muya、CodeMirror、跨模式撤销与重做、批注锚点、图片粘贴与拖放、全部 33 套主题及 HTML 导出；仅切换模式或主题时保留原草稿，不产生额外编辑。
- `pnpm test:app:ui` 验证实际主进程、预加载桥接和后台服务，覆盖启动时及运行中打开文件、真实键盘撤销重做和保存、最近记录右键菜单、主题设置和单文件功能边界。

WSL 用例验证 UNC／绝对路径解析，不等同于真实远程项目连接测试。发布流程在上传安装包前执行这些检查。
